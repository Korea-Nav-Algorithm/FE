# 내비게이션 화면 구성

TMAP 공식 주행 화면과 경로 선택 화면의 배치·색상·타이포그래피를 기준으로 구현한다. 별도 이미지·폰트·아이콘 패키지를 추가하지 않으며 실제 경로와 기존 상태를 표시한다.

## 화면 상태

- 탐색: 56px 높이의 흰 pill 검색창과 밝은 회색 하단 바로가기 패널. 장소 선택은 모바일 전체 높이의 흰 검색 화면으로 열고 이름·주소를 목록으로 보여준다. 좌표 입력은 접어 둔다.
- 경로 준비: 흰 상단 영역에 현재 위치·목적지 회색 필드를 두 줄로 배치한다. 경로 카드는 파랑(`#0068ff`) 2px 테두리, 12px 모서리, 38px ETA로 구성한다. 카드 아래 56px 높이의 `안내시작` 버튼을 둔다. 교통 신뢰도와 네 색상 범례는 카드 안에 유지한다.
- 주행: 왼쪽에 붙은 초록(`#176947`) 안내판에 흰 방향 화살표, 50px 거리 숫자, 25px 단위, 도로명을 배치한다. 하단 흰 바는 목적지·26px 도착 시각·남은 시간과 거리·종료 및 진단 메뉴로 구성한다. 지도 위 속도 숫자는 39px이며 조작 버튼은 48px 흰 원형이다.
- 지도: 흰 테두리의 9px 교통색 경로선 위에 흰 진행 화살표를 반복 표시한다. 정보 없는 구간은 회색을 유지한다. 차량 마커는 흰 원 안의 파란 화살표이며 유효한 heading으로 회전한다. follow 주행은 35도 pitch로 차량을 지도 가시영역 아래쪽에 둔다. 전체 경로를 누르면 follow를 해제하고 북쪽 기준 평면으로 돌아간다.
- GPS 약함·오프라인 상태와 DBG는 하단 footer에 작게 표시한다. 상세 정보는 진단 패널에 둔다. API 오류와 재시도도 하단에 배치한다.

## 배치 및 입력

- `ResizeObserver`가 하단 카드의 실제 높이를 측정한다. 지도 버튼·속도계·출처 표시는 카드 위로 이동하며 경로 전체 보기의 padding도 이를 반영한다.
- 900px 이상에서는 검색창과 하단 카드가 왼쪽 380px 패널이 되고 지도는 오른쪽 여백을 이용한다. 모바일 경로 카드는 좌우 16px 여백을 두고 주행 도착정보 바는 전체 폭으로 표시한다.
- 주요 버튼의 터치 영역은 최소 48px이다. 목적지 시트는 Escape·닫기·바깥 터치로 닫고 키보드 초점은 시트 내부에서 이동하며 닫힌 뒤 복원한다.
- 교통 범례는 지도 위 고정 좌표가 아닌 하단 카드의 문서 흐름에 포함되어 안내 문구가 길어져도 서로 겹치지 않는다.
